# Folio Workbench for Android

Every PDF tool in one free app: merge, split, compress, convert, edit, sign, redact, OCR and more.
Files never leave the device. Developed by **Sourabh Tilawat**.

- `app/` — Android app (WebView shell + the offline web app in `app/src/main/assets/www`)
- `.github/workflows/build.yml` — builds the release app bundle on every push to `main`;
  the result appears on the `builds` branch
